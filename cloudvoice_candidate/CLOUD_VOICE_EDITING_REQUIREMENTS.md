# 当前配音修改范围

独立预览支持三个音频流程：生成新WAV、修改全文重生成、局部句段重生成并接回完整WAV。无视频选择、音画同步和MP4导出入口，视频工作在工作室完成。旧的视频辅助函数仅保留兼容性，不在本客户端开放。

局部修改提交前保存原音轨快照，检查文件指纹、时间范围、自然安静边界和可选SRT。连接时保留替换音频全部样本，最多3dB音量匹配，在安静边界作5ms淡化。没有安全接点则停止，保留已有结果和原素材。输出完整音频、接缝试听、报告；可选SRT区间外按时长差平移，新区间仅估算，需复核。

生成前的语气、速度、音量、降噪独立保存并随任务快照传递。语气是模型提示，音量/降噪/速度是音频处理，制作记录可核查。原稿与读音稿分离，不能把设置送达等同于发音或音色验收。

普通音频微调不需云端或文本，保留原文件和声道；生成语气必须重新提供或复用对应正文。微调后清除旧字幕关联。上一版试听和输出记录用于对比，不自动评价哪版更好。

恢复同一已提交任务不会重复推送；本地连接失败复用已生成WAV。远端失败为终止状态，必须先诊断再主动新建任务。0.4在失败作业已保存可校验断点输出时支持新作业复用完成段；平台未保留输出或没有完整段落时不能续，仍有模型启动成本。

完整操作、模板与验证限制以 README_CLOUD_PREVIEW.zh-CN.md 为准。
