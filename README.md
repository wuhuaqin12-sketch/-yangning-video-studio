# 杨宁视频工作室

Windows 桌面视频制作工具：压缩停顿、同步字幕，合成背景、标题、重点词与封面。

## 下载与安装

在本仓库的 **Releases** 中下载最新的 Windows ZIP，完整解压，双击 **INSTALL.bat**。
安装后从桌面“杨宁视频工作室”打开。首次安装需要联网准备 Python、FFmpeg 和运行依赖。

## 更新与分享

正式发布包内置同一个固定更新地址。启动后会检查新版，经使用者确认后安装，重新打开软件生效。
安装包可以分享给朋友。素材、成片和排版设置保存在各自的电脑上。
旧 ZIP 版请先改用桌面安装版；尚未配置更新地址的 0.11.0 版也需要安装一次本次发布版。

## 制作

选择视频及对应原视频时间轴的 SRT，设置标题、背景和字幕样式并保存排版，点击“制作并导出成片”。
成片使用本次优化后的字幕时间轴。过长字幕保持统一字号并分屏显示。
分屏切换按文字长度在原句时段内分配，并非逐词语音定位。

## 发布维护

正式发布前只需在 release.json 中更新版本号；make_release.py 打包时会自动同步安装包内 program/desktop_update.py 与 program/engine.py 的版本号，无需手工逐个修改。
推送到 main 后自动运行测试与 Windows 安装检查，但不会直接公开发布。确认发布时，在 GitHub Actions 中运行“Test and publish desktop app”，输入 RELEASE；测试通过后自动创建公开 Release、Windows ZIP 和 latest.json。发布版本号不能与现有公开版本重复。
已发布的同版本安装包不覆盖。下载校验失败时不切换当前版本。

## 声音处理（0.11.4）

声音页面提供“一键降噪并生成试听”，执行人声分离和加强降噪，并提供“查看 / 复制本次去噪指令”。
V11 加强降噪使用 RNNoise bd 模型、75Hz 高通和温和点击声清理，补偿 48kHz 下的 480 个采样延迟并保持原采样数。
温和降噪继续保留；关闭降噪仍使用原声。加强降噪模型随完整发布包提供，并校验 SHA-256。

句前多余颤音可能被识别为人声；不能只凭音量或字幕缺失自动删除。当前版本不自动理解或逐词对齐字幕。
对照当前音频对应的字幕正文，在“试听与修改片段”对比原声与处理后音频，确认后选择“这段静音”，可撤销。
不把本次 V11 的具体秒数套用到其他文件。静音不改变时长；另选倍速、空白剪短或剪掉片段时按相应制作规则执行。

原素材与原声保留。技术检查不等于逐句听辨，重叠杂声可能残留；不能认证任意素材均与本次 V11 听感一致。
仅降噪可离线使用；人声分离首次联网下载单独运行环境与模型，支持 Python 3.10–3.12，准备后在本机处理。

模型来源：richardpl/arnndn-models，固定修订 0fda24c46d78f0207d820bb970fbe85c1971b39c；模型作者 Gregor Richards。

## 声音报告与专用字幕（0.11.4）

新增“一键降噪并生成试听”，点击即启用人声分离和加强降噪并启动处理。声音页面可独立选择“对应这段音频的字幕 SRT”，不会替换原视频字幕。校验格式、顺序和音频时长范围，不认证实际讲话与字幕逐字相符；不自动静音字幕空白。
每次分析、静音/剪掉或撤销后保存“声音处理明细.txt / .csv / .json”，声音页面和试听修改页面均可打开。
报告列出整段处理范围、明显减弱区间、人工静音（含淡化范围）、剪掉和新增静音停顿，附原素材/原配音与成片时间、倍速、按时间段重叠的字幕文字。
明显减弱以100毫秒窗口、至少6dB衰减持续至少300毫秒记录，排除整体峰值限幅增益；这是信号变化，不能直接认定为噪音已清除。分离后启用降噪时，衰减比较以分离后人声为基准。
完全剪掉的片段标注“成片无此区间”；部分重叠时只列仍保留的成片区间。撤销后更新报告，不累计已撤销的静音。

一键降噪生成整段原声/处理后试听，采用独立文件名，局部试听不会覆盖整段试听，随后可换时间范围继续听、静音、剪掉或撤销，明细同步重建。混在讲话里的残留应从原声重新选择降噪方案，不默认反复叠加处理。

建议制作顺序：去噪 → 整段试听 → 修正残留 → 剪短空白/调整倍速 → 同步字幕并制作成片。配音工程的整段去噪试听使用原速、未剪停顿的处理后音频；报告同时提供原配音和成片坐标。

主页面按五步排列：选择素材 → 去噪与整段试听 → 停顿与速度 → 标题/字幕样式/封面 → 导出。高级与批量选项移入更多设置。小屏可使用页面滚动条。
对相同素材导出时沿用已试听工程，保留静音/手动修改；停顿和排版可后设。声音选项或字幕变动需重新准备工程，原有工程保留。改变输出目录时拷贝成片、字幕与报告，不重复压缩。

整段试听按音频修订使用不同文件名，避免正在播放上一版时覆盖它；局部试听不会覆盖整段文件。

## 安装修复（0.11.5）

INSTALL.bat / START.bat 会实际检查每个候选 Python，跳过商店版/WindowsApps 来源和不可运行的旧环境，优先普通版64位Python3.12；缺少合适解释器时通过 winget 准备普通版Python3.12。
私有运行环境须同时具备 pyvenv.cfg、可启动的解释器、正确的虚拟环境目录和 pip。检查失败会先保留 runtime.failed_* 备份，再重建，不删除素材或成片；正在运行的私有环境不会原地改名。
遇到旧版“Actual environment location may have moved / No pyvenv.cfg file”安装失败，请关闭程序，下载本版、完整解压后重新运行 INSTALL.bat。安装成功后再从桌面图标启动。
