# 杨宁视频工作室 · 手机本机版 0.2

独立的手机版音画同步试用入口。Windows 正式程序、版本、检查更新和稳定恢复包不变。默认竖版540p，可选720p、24fps。

## 使用

1. 导入正文视频、提前准备的外语配音和SRT。默认开启自动音画同步：SRT文字对应配音，SRT时间对应原视频画面。
2. 需要时勾选片头、片尾。片头可保留整轨原声，或舍弃整轨后混合外部纯音乐与外语配音。片头SRT单独从0秒开始；片尾完整保留原声。
3. 背景、封面、字幕设置在一个入口。新字幕烧录默认关闭。
4. 可先导出20秒试听预览，也可直接合成完整视频。文件名用中文标注横版/竖版及预览/完整用途。
5. 如果SRT已经按现有配音准确计时，可以关闭自动同步，按原画面时间合成。

自动同步保持原配音采样顺序和语速；根据逐句定位结果调整画面播放速度，保留原画面开头及无字幕尾部。**成片时长会随配音调整，不承诺维持原视频总时长，也不是嘴型生成。** 封面、片头和正文的SRT分别偏移，片尾不会按SRT末尾被截断。

## 实现与质量限制

浏览器 WebCodecs + Mediabunny 1.66.0 合成。语音定位使用 Transformers.js 3.8.1 + ONNX Runtime WASM，Whisper base_timestamped q8，固定revision `608c49e61301901684bc36cac8f74b95ff6b5a8e`。首次下载约77MB权重及约32MB运行时；日语另下载约18MB本机读音字典。下载失败明确报错，不切换到云端。

逐句对照用户SRT，ASR文字不替换用户文字。日语先核对原文字；同音汉字导致失败时，用本机kuromoji/IPADIC读音复核，使用更严格的覆盖率门槛。所有句子都必须通过，发现漏句、顺序异常、低匹配、无效时间或句间无法连续映射时停止。分数是文字/读音匹配程度，不是同步准确率保证。轻量模型仍可能误定位专名和佛教术语，必须试听真实素材。

模型最后一个词的小幅补零越界仅在0.8秒以内约束到真实音频末尾；其他异常不通过整段缩放掩盖。配音、字幕缺失或语言未实现时明确失败。日语/英语/法语/德语/印尼语/普通话有处理入口；目前只有日语受控多句同步完成浏览器实测。粤语及其他语言自动同步不开放，不冒用普通话识别。

定位结果及已选默认片头音乐保存在当前浏览器；更改字号/比例可复用定位缓存。用户视频、音频、图片、SRT和缓存不上传。首次模型下载需要联网，网页不承诺离线或锁屏后台运行。

不含电脑版的原中文字幕清除、人声分离、语音生成和批量队列。关闭同步时的“延长静止末帧”只是独立回退选项，不称为逐句同步。

单次素材合计300MB、成片10分钟。较长文字另有本机比对内存上限，会提示分段；这些是保护上限，不是所有手机都能完成的性能保证。iPhone/Android实机、长视频尚未认证。

## 构建与测试

Node 20+。`ONNXRUNTIME_NODE_INSTALL_CUDA=skip npm ci`，`npm test`，`npm run build`。只使用浏览器WASM，安装时跳过与本项目无关的ONNX Node CUDA包。

`src/engine.mjs` 实际合成；`src/sync.mjs` 参考稿匹配和分句画面映射；`src/alignment-worker.mjs` 本机语音模型；`src/japanese-reading.mjs` 日语读音核对；`src/app.mjs` 主UI。`qa.html` 旧6/27秒混音回归，`sync-qa.mjs` 内部同步验收。公开日语评测音频只用于本地QA，不包含在发布素材中。

当前浏览器测试记录见 `dist/verification.json`。云端桌面Chrome通过，不代表物理手机通过。代码在独立手机版分支中，未修改电脑正式更新源。

内部日语同步验收重现：`python scripts/generate-sync-samples.py`，`YANGNING_SYNC_QA=1 npm run build`，然后在浏览器打开`/sync-qa.html`。验收数据和页面不得进入正式发布档案。下载结果后可用`YANGNING_QA_OUTPUT=<目录> python scripts/verify-sync-output.py`检查。
