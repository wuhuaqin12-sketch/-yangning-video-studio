# 杨宁视频工作室 · 手机本机版 0.1

独立的手机版试用入口，设计与现有 YangNing VideoStudio 一致。Windows 正式程序、版本、检查更新和稳定恢复包不变。

浏览器使用 WebCodecs + Mediabunny 1.66.0 本机处理，用户素材不上传。浏览器不支持 AVC 编码时明确停止；AAC 缺少原生支持时使用本机 WASM AAC 扩展，不静默改为云端。

支持正文视频+现成配音、按配音时间的SRT、烧录字幕、片头/片尾、片头BGM+配音整轨替换、背景/静音封面、竖版标题、分行/分屏、双比例完整MP4和SRT。默认竖版540p，可选720p、24fps。

不支持电脑版的烧录中文字幕清除、人声分离、语音识别、逐句自动音画匹配和批量队列。配音较长只能经勾选延长静止末帧，不会加速、截断。SRT应对应当前音轨，而非未调整的原中文时间轴。

先用内置6秒样例，再用20秒实际素材验证手机。单次素材合计上限300MB、成片10分钟；这是保护上限，不是设备性能保证。iPhone/Android实机、长视频、后台处理仍未认证。需要保持页面前台，不能宣称是电脑正式版的完整替代品。

## 构建

Node 20+。安装 `npm ci`，执行 `npm test`、`npm run build`。dist 已含本次合成的非用户测试素材；重建样例需要 FFmpeg 和 Python Pillow：`python scripts/generate-samples.py`。

`src/engine.mjs` 是实际合成引擎；`src/core.mjs` 为可测试的SRT/排版/时轴逻辑。主UI `src/app.mjs`。`qa.html` 用相同引擎执行合成色块与音调的综合验收。

## 实际验证

- 5项纯逻辑测试通过：字幕、重叠校验、长配音防截断、时间偏移、比例适配与分页。
- 实际浏览器导出6秒竖版MP4，验证三段画面和330/660/880Hz音轨，整段解码通过。
- 实际浏览器导出两份27秒MP4，各648帧，横960x540/竖540x960；完整清晰封面、封面静音、片头纯音乐+配音且旧音轨消失、正文配音替换、完整片尾原声、字幕烧录、片头/正文SRT偏移及完整解码通过。见dist/verification.json。
- 验证环境为云端桌面Chrome，不是物理iPhone或Android；这些设备和5分钟以上真实素材尚未验证。
