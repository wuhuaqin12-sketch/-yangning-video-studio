杨宁视频工作室 Windows 桌面版 0.11.1

第一次使用
1. 关闭旧软件，完整解压本包。
2. 双击 INSTALL.bat（首次安装可能需要联网安装 Python、依赖及 FFmpeg）。
3. 安装完成后，从桌面“杨宁视频工作室”打开。以后不必重复解压或运行 START.bat。
4. 标题、背景、字幕样式设置好后，点“保存排版”，回主界面一键导出。

更新
本次正式发布版内置 GitHub 的固定更新地址。
正式发布完成后，启动会自动检查；发现新版后，点同意即可下载安装，再重新打开软件。
联网更新会校验下载大小及 SHA-256，失败或取消时不切换版本。
“更新设置”中也可设置发布者提供的 HTTPS 地址、从 ZIP 更新包升级或恢复上一版。
从 ZIP 升级仍需下载该更新包，作为尚未接通联网更新时的备用方式。

分享
本包可以发给使用 Windows 的朋友，由对方运行 INSTALL.bat。
大家使用同一个发布地址即可收到同一版本更新。
各人的素材、成片和设置分别留在各自电脑上，不互相传输。

数据与版本
沿用原工具的个人设置和任务记录。
更新包只放程序，用户视频与输出文件不放进更新包。
程序版本目录在用户本机，保留上一版；不会自动删除旧输出。
“恢复上一版”仅恢复程序，不还原其他版本对设置或依赖做出的变更。

验证状态
已在 Linux 环境验证更新逻辑和实际视频导出。
本环境无法执行 Windows 安装器、桌面快捷方式和原生窗口，需要在 Windows 电脑实际验证。
本包不是独立 EXE；首次安装器会准备需要的运行环境。
