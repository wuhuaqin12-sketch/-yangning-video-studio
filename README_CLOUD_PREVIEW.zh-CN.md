# 杨宁云端语音 · 独立试用包

这是独立试用版，不覆盖现有工作室12.11，不在电脑安装VoxCPM2或PyTorch。源码已接入工作室草稿PR #3；此包用于先验证账号连接和实际GPU试听，不是正式工作室升级包。

## 首次打开

1. 在Windows电脑上将整个ZIP解压到自己的普通文件夹，例如“下载/杨宁云端语音试用”。不要直接在ZIP里面启动。
2. 双击 `START_CLOUD_VOICE_PREVIEW.bat`。脚本会寻找64位Python3.12/3.11；缺少时通过Windows软件包管理器准备Python3.12。随后在本文件夹创建独立运行环境，安装小型客户端依赖并检查/准备FFmpeg。首次需要联网，可能需等待数分钟。
3. 成功后会创建桌面 `YangNing Voice Cloud Preview` 快捷方式。以后从此快捷方式打开，无需重复安装。移动解压文件夹后需重新运行启动文件以更新快捷方式。

此启动流程没有开通付费GPU、GPT API或付费订阅。免费Kaggle账号的剩余额度、验证要求、分配硬件和排队情况以账号页面为准。

## 只需本人配置一次的账号信息

- Kaggle用户名及本人访问令牌/API Key。令牌在界面的遮挡输入框中填写并保存到Windows凭据库，不要把令牌发在聊天或放到公开仓库。
- 本人可以读取的**私有Kaggle Dataset**，其标识为 `用户名/数据集slug`。数据集中放入原始10秒1626参考文件，文件名改为 `1626_reference.wav`；只改文件名，不转换格式、不重新编码。程序会核对固定SHA256。
- 参考文件：[1626老师10秒原声](https://chatgpt.com/library?file_id=libfile_5bb1586d1ed08191b0898f013b5382e2&account_id=personal)。请保持Dataset为Private，仅授权给组员。每位组员使用自己的Kaggle令牌和账号额度。

Kaggle登录、令牌和私有Dataset尚未在本聊天环境中配置，因此这里没有执行过真实GPU生成。

## 先做短试听

打开语音窗口，保存连接信息，选择语言和倍数，粘贴一小段完整句子，点击“生成克隆试听”。模型固定VoxCPM2 2.0.3，以1626原声为唯一音色参考。日语默认0.84倍，英/法/德默认0.9倍；可手动选择0.5到2.0倍，始终保音高。模板音频不进入模型，语气由文字预设引导，详细模板韵律匹配尚未实现。

## 改一小段并导出完整短片

1. 选择“只重做选定句段并导出完整短片”。选择已经配音、只有一小段要修改的**当前成片MP4**；若有单独且已对齐的配音WAV也可选入，留空则取视频音轨。
2. 选择与当前成片时间轴一致的SRT，再点“从字幕选句段”选择一句或连续几句；也可手动填写起止秒数。文字区载入后，修改错误文字。尽量包含完整句子和前后停顿。
3. 点击生成。新配音取回后，程序会寻找安静接点、做轻微响度匹配，将其接回整条音轨，调整对应画面时长及后续字幕时间，然后导出完整MP4、完整WAV和新SRT。原文件保留。

若接点正在发音、字幕句子被切开，程序会停止并保留任务，不强行拼接。新区间SRT目前按句子长度估算，仍需校对；画面里已经烧录的旧字幕不会被抹除，应使用干净源视频。输出文件夹保存左右接缝的WAV试听片段，需人工检查接缝、音色和术语读音。

## 全文重做

选择“修改全文后重新生成”，导入TXT/SRT或粘贴完整正文。若只需要音频，直接生成；若还需要完整视频，选择当前视频并勾选“全文模式也同时导出完整短片”。

## 中断后

重新打开窗口，点击“恢复最近任务”。提交身份、云端已生成音频和本地合成状态都会保留；已生成的语音不会因为本地合成失败而重新提交GPU。修改正文需要创建新任务。接点范围不合适时，应重新选择包含完整句子与自然停顿的范围。

## 验证状态

- 22项本地自动测试通过：包含真实FFmpeg局部/全文MP4导出、音高/时长/停顿、保留区间外音频、字幕后移、任务恢复和源文件变化检测。
- 通过Python语法检查，打包文件逐个有SHA256记录。
- Windows图形界面、PowerShell自动安装、实际Kaggle授权和GPU推理尚未在此环境端到端验证。首次实际试听可能暴露云端依赖/显存问题，需要根据报错继续修复，不能把本包当成已验收正式版。
