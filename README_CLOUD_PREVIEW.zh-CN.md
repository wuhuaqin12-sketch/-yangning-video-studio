# 杨宁云端语音克隆 · 0.2 独立试用版

双击 START_CLOUD_VOICE_PREVIEW.bat 启动。关闭旧试用窗口后，将此包解压到原试用目录并覆盖同名文件；连接信息保留。此包不升级或覆盖工作室12.11。

默认选择“生成新音频”：输入文字或导入TXT/SRT，点击“生成音频”。不需要视频。

“修改全文后重新生成”：粘贴或导入修改后的完整正文，直接重新生成整篇WAV，不需要原音频。

“局部改读音并接回原音频”：选择原WAV和替换起止秒数，可用配套SRT选择连续句段；正文只填写修改后的句段。提交GPU前检查接点并保存原音频快照，生成后匹配音量、保留停顿，在静音处作5毫秒淡入淡出，输出完整修正WAV和两处接缝试听，原文件保留。原文件变化或接点落在连续语音中会停止，避免误剪。局部拼接失败时可恢复已生成的句段而不重复消耗GPU。

如附配套SRT，区间外字幕按时长差平移，新句段字幕仅按文本长度估算，需校对。局部连接效果仍须听检，不能保证所有生成结果都没有可闻接缝。

本工具不选择视频、不处理音画同步或导出MP4；视频工作统一在杨宁工作室完成。

## 2026-11-10 更新

日语新增“佛教术语读音校正”（默认开启）、“预览实际朗读稿”和“编辑术语读音表”。原稿及字幕保留汉字，只有送给模型的朗读文本替换为项目约定假名。词典采用最新校对表，例如執着=しゅうじゃく、欲界=よくかい；短词不覆盖更长术语。单独的“相”“は”“へ”不做全局机械替换。稀有或依赖语境的词列出待确认项，可手动添加或覆盖读音，保存后复用。非日语不套用此词典。

原稿、实际朗读稿、替换记录分别输出。局部修改时用读音稿生成声音，用原汉字正文更新配套SRT。读音表解决的是文字输入歧义，不保证重音、长短音或所有实际发音自动正确，仍须试听；不能将未听检的输出标记为已验收。

所有六种语言默认倍数统一为1.0。第一次启动此新版会将旧版保存的0.84、0.9等倍数重置为1.0；此后仍可手动选择倍数。语气模板不改变倍数，不复制模板的绝对音高。

“语气参考”默认载入已提供的日语模板和英语模板。日语用日语模板；英语、法语、德语用英语模板。粤语、印尼语暂未内置已确认模板，可自行选择音频或留空使用本语言自然语气。支持每种语言单独选择、更换模板。

模板只在本机分析最多前120秒的内部停顿与相对音高变化，转成柔和连贯的文字提示。模板原始波形、音色嵌入、绝对音高都不会送入模型；reference_wav_path只有已确认的1626原声，prompt_wav_path和prompt_text始终为空。模板摘要不能逐句精确转移语调，效果需试听。模板不用于加速、减速或剪掉自然停顿。

本包包含用户提供的两份语气模板，适合授权团队内部使用。源码仓库不包含这些音频。
