# YangNing CloudVoice 0.7.0 · SRT智能停顿正式版

独立于YangNing VideoStudio；不会升级或覆盖VideoStudio 12.11。完整解压后运行START_CLOUD_VOICE_PREVIEW.bat。已有用户通过原有“检查更新→更新并重启”升级。

## 本版使用

- SRT：保留编号、起止毫秒和正文。每条单独生成，按绝对开始时间放置；较短句子补静音。超时句子完整保留，后句顺延并保留原句间间隔，明确报告超时及偏移，不保证超时素材仍能严格对齐原视频。
- TXT：按逗号、句号、问号、分号和换行划分完整语义句段，使用最低停顿；已有自然静音不会剪短。小数、数字分组和常见英语缩写不当作标点断开。句段分拆可能影响连贯性，生成后需试听。
- 支持六种现有语言，默认1.0倍；老师原声始终按SHA256校验，模板只用于节奏摘要。支持本机及Kaggle云端，局部改读与全文重做、普通微调和版本保留。
- “打开音频所在文件夹”定位最新生成WAV；文件名使用导出时的日本时间和任务编号。更多设置可看停顿／超时报告；同时保留原始SRT。
- “取消生成”：本机停止模型进程并保留已写断点；云端只对本次私有作业发送删除／取消请求，不删除数据集。平台拒绝或网络未确认时明确显示待确认，不能保证GPU立即释放。生成已完成或文件复制阶段可能赶不上取消。
- 首次本机模型安装按需进行，旧模型缓存、独立环境、设置和模板不会被代码更新删除；依赖未变化时新更新器复用客户端环境。旧更新器首次过渡可能准备轻量客户端环境，不会重装本机模型。

## 平常生成

1. 主页面粘贴正文，或导入UTF-8 TXT / SRT；SRT编号和时间码不参与朗读。
2. 选择语言、倍数和语气。各语言初始默认1.0倍；自然、柔和连贯、平和讲课可直接选择。
3. 点击生成音频，或先预听约15秒。只需要正文，无需视频。生成前的详细语气、音量、降噪选项位于“更多设置 → 生成设置”。

每种语言的速度、模板和详细语气独立保存。点击“保存当前语言设置”可在未生成前保存；生成提交也会保存。语言切换保留当前语言的选项；正文草稿按新建、全文、局部三种模式分别保留。保存的设置不是永久锁定，可恢复默认。

支持的快捷指令仅为已列出的命令，不是任意自然语言理解。先识别并应用到控件，再查看生成设置中的摘要。未识别或相互矛盾的要求会被拦下；未应用的指令不会偷偷忽略后生成。

速度、音量、轻度降噪由生成后的音频处理执行；柔和、连贯、平和、抑扬、停顿方式和强调由生成时的模型文字提示控制，实际效果必须试听，不能保证每次完全符合要求。默认轻度降噪开、音量0dB。只做一次所选速度处理，保音高、不自动剪掉停顿。

## 更多设置

- 连接与输出：Kaggle用户名、私有Dataset、令牌安全保存、输出目录、种子、最近任务日志和本机音频环境检查。
- 生成设置：语气细调、音量、可选降噪、快捷指令、恢复默认。
- 模板与读音：每语言语气模板；日语术语校正、实际朗读稿预览和用户读音表。
- 修改原音频：全文重做，或选择原音频和完整句段作局部修改。

小屏幕上的详细设置提供滚动条。主页面保留生成、试听、微调、版本比较和任务状态，不堆叠视频选项。

## 目标音色和模板

模型的唯一音色参考是已确认的老师原声。原文件字节必须保留，兼容1626_reference.wav和1626_reference.wav.wav，递归查找新旧Kaggle输入路径并验证SHA256。不要重新编码参考文件。

本包私下附带用户的日语和英语语气模板，源码仓库不含这些音频。日语用日语模板，英法德默认用英语模板的节奏摘要；粤语、印尼语尚无已确认的内置模板，可留空使用本语言自然语气。

模板在本机分析最多前120秒的内部停顿和相对起伏，转为语气提示。原波形、音色嵌入和绝对音高不传入模型，prompt_wav_path和prompt_text为空。模板不会改变所选倍数，也不能逐句准确复刻语调；参考输入固定不等于已经验证实际输出音色完全一致。

日语读音校正只改变送入TTS的读音稿，原稿和字幕保持汉字。内置项目读音包括執着=しゅうじゃく、欲界=よくかい；最长术语优先，不全局机械替换单字“相”或助词“は/へ”。用户可新增或覆盖假名。待确认项按语境校对。输出原稿、读音稿和术语替换记录；假名处理不等于实际音频已经读对。其他语言不套用日语读音表。

## 局部修改和全文重做

全文重做：提供修改后的完整正文，导出新的整篇WAV，不需原音频。

局部修改目前使用单声道独立配音，以免静默混合立体声或背景音乐。在更多设置选择原音频、起止秒数，或从配套SRT选择连续完整句段。主页面只填替换后的句段正文。提交GPU前检查边界和原文件，保存快照；生成后最多3dB音量匹配，在安静边界作5ms淡入淡出，保留替换音频的所有样本和停顿。输出完整新WAV、接缝试听、修改报告，以及可选的平移后SRT。

没有安全接点或原文件变化时停止，保留已有结果。若云端音频已下载而本地拼接失败，恢复最近任务会重试本地连接，不重复生成。新区间SRT按句长估算，需要人工校对；区间外字幕按时长差平移。接缝仍需试听。

此预览工具不选择视频、不处理音画同步、不导出MP4。视频工作在杨宁工作室完成。

## 普通音频微调和版本比较

“音频微调”可选择已有WAV / MP3 / M4A / FLAC，直接做保音高变速、音量和可选轻度降噪，无需云端GPU或正文。输出新WAV及处理记录，原文件不变；单声道保留单声道，双声道保留双声道。增加音量附有限幅；多声道拒绝静默混音。

后期滤镜不能直接让说话方式柔和、连贯。要改变语气，先提供对应正文或替换句段，再打开生成设置重新生成。外部音频不会自动转录。主页面可试听上一版、查看版本记录及打开输出文件夹。微调改变时长后不能沿用旧SRT当作已经同步的字幕，程序会清除旧SRT关联。

## 连接、任务和恢复

首次在更多设置填写本人Kaggle用户名、本人可访问的私有Dataset、令牌；令牌只保存到本机Windows凭据库，不写入JSON或Notebook。安全保存表示本机保存成功，不表示云端GPU权限已经验证。账号需具备GPU与Internet权限，免费GPU可用性和等待时间以账号实际状态为准。

任务状态区分“等待分配资源”和“云端运行”。可获得运行日志时进一步显示安装依赖、模型下载、生成、音频处理阶段；无法取得日志时只显示实际运行状态，不伪造百分比。提交身份会在请求前持久化，网络超时恢复不重复提交。

远端已失败/取消的任务不会靠等待或恢复重新运行；请查看日志，修正后主动生成新任务。长文续生成的条件与操作见下方0.4更新说明。云端执行成功且本地输出验证后才清理私有Notebook；清理失败保留记录可重试。已完成文件被移动/删除时不会再显示虚假成功。

关闭语音窗口时，正在处理的本机任务保持后台窗口和消息处理；重新打开复用该窗口。退出整个程序会停止本机处理，但已提交云端任务身份保留，可重启恢复。未完成草稿以最近保存为准。

## 自动选择语气模板（0.3-preview.3）

“更多设置 → 模板与读音”新增：自动选择、手动指定、自然语气（无模板）。每种语言单独保存，在模板与读音页显示实际使用来源。

自动选择按本机已标记的语言文件匹配，优先 japanese.wav / english.wav / french.wav / german.wav / cantonese.wav / indonesian.wav。当前私下包只附日语、英语两份真实模板，没有虚构其余音频：法语、德语缺少本语言模板时沿用已确认的英语节奏摘要；粤语、印尼语缺少模板时采用相应语言的自然语气预设，并明确显示“未使用音频模板”。以后有本语言素材时才会优先选它。按文件标签匹配不是自动识别语言、口音或母语质量。

手动模式的文件丢失会阻止提交，不会偷偷更换；自然语气模式完全不分析模板。自动选择不会从互联网抓取陌生音色，任何模式都只有老师原声进入模型的音色参考输入。按用户确认范围保留粤语，不提供越南语入口。


## 再次复查更新（0.3-preview.4）

更换原音频会清空旧SRT与旧起止范围，局部修改必须重新选段；默认不再预填0至1秒，避免误替换。明确手动指定的模板丢失时不自动替换为另一个同名内置素材。

生成和普通微调会附带波形检查记录，可在“版本与输出文件 → 查看波形检查”查看音量过低、接近满幅样本和超过3秒内部低能量间隔的复听提示。检测分块读取，不将整篇音频载入内存；普通微调的哈希检查也采用分块读取。这些提示不等于漏读、音色或发音验收，不自动裁剪停顿。


## 0.4：预听、句段修改与长文断点

- 主页面“先预听约15秒”按当前语言、老师音色、语气、读音和后期设置，从正文取完整语句试听；不强切发音，实际时长可能超过15秒。试听单独保存，通过“试听预听”播放，不替换正文或已完成的整篇音频。预听与全文是独立作业，都会占用免费GPU额度，启动仍可能需要排队/下载模型。
- “术语集中试听”位于模板与读音页。日语可从正文提取已知及待确认术语，其他语言每行输入需试听词；采用当前配置另生成一段。试听不是词典自动确认，不修改全文。
- 新生成WAV附带以文件哈希绑定的句段表。“按句段试听 / 修改”可选一个或连续语义段，试听或载入修改，生成后接回整篇WAV。单位为生成时的完整语义段，可能含多句；不是逐词ASR对齐。变速后的边界按总时长比例估算，拼接前仍查安静边界。按完整句段修改后保存更新的句段表，可继续修改下一处。普通外部音频和没有对应表的旧音频仍使用SRT/时间范围。
- 云端每完成一个段落就保存无损浮点断点文件和文字/参数/模型快照校验记录，不等整篇完成。可处理的Python异常会被记录为失败结果并正常保存作业输出，方便新作业读取断点；客户端不会把这种正常保存误判成音频生成成功。平台强制杀死或取消时，仍只能尝试下载平台实际保留的断点。点击更多设置 → 连接与输出 → “续生成未完成段”，核对成功后提交新的私有作业，复用已完成段落，只生成缺段。原文或设置改变则不能混用旧断点；模型快照、采样率或精度不同也拒绝复用。
- 续生成取决于Kaggle是否保留并允许读取失败作业输出；依赖安装阶段就失败、没有完成任何段落、平台未保存输出或文件损坏时不能续。程序会说明原因，不静默从头生成。续作业仍有环境与模型启动成本；不能保证免排队或完全不消耗GPU。
- 为续作业保留来源私有Notebook，直到完整输出在本机验证后再清理整条链。网络超时用“恢复最近任务”查询同一个任务，不重复提交；确认远端失败并已有有效断点时才用“续生成未完成段”。
- “加入本语言模板库（以后自动选择）”可在有素材时选择一次：程序检查音频并保存到本机该语言模板库。之后自动模式优先选它，不需每次指定文件；没有对应素材时仍显示实际备用来源/自然预设。六种语言独立，越南语不加入。建议自然母语讲课模板约30秒，20～40秒即可，最多保存/分析前120秒。

0.4的断点、句段、预听流程通过模拟模型/云端接口和实际FFmpeg的程序验证；尚未完成新的Kaggle断点端到端实测及听感验收。平台保留输出、跨作业附件权限和老师音色/术语读音需要实际任务继续确认。


界面统一使用“老师音色 / 老师原声”，不向组员展示原素材编号。云端固定参考文件名和校验值作为内部兼容标识保留，引用素材没有变化；新输出使用TeacherVoice文件前缀。


## 0.5：检查更新与恢复上一版

主页面和独立启动窗口都有“检查更新”。它只查询语音工具自己的更新渠道，不查询或安装视频工作室的更新。首次使用此功能需要先安装这个带更新按钮的版本；以后有已发布的新版本可在窗口内查看说明，点击“更新并重启”，不再手动解压覆盖。

更新过程会下载固定源码版本的代码包，核对整个包与每个文件的SHA256和产品标识；不会接受任意网址、其他软件包或模板/用户数据目录。更新渠道公开的只是本来已公开的程序源码，不上传个人语气音频或Kaggle令牌。

先在独立的新Python环境中准备依赖，再退出旧程序、备份受管理的程序文件、替换并检查新版启动。新版本没有完成启动确认时恢复原程序与原环境，再打开旧版。成功后可以使用“恢复上一版本”。连接设置、凭据库、语气模板库、历史音频和旧的运行环境均不被覆盖。

音频生成、模板处理或微调正在运行时不安装更新，避免中断任务。准备更新期间也不能发起新的处理任务。联网失败、校验失败或依赖准备失败时保留原程序；错误会在检查窗口说明。更新依然需要网络，下载速度取决于当地访问GitHub的情况。

维护者在新版本通过验证后，使用 build_cloud_voice_update.py 生成不含私人模板的更新载荷，并发布到独立 cloud-voice-preview-updates 分支。载荷地址固定到完整提交哈希，渠道文件再指向该载荷；更新版本和序号来自 cloud_voice_version.py，每次发布必须递增序号。

## 0.5-preview.3：减少重复等待

默认勾选“全文同时导出短试听”和“正文和设置相同时复用已完成音频”，均可在更多设置→生成设置关闭。直接点生成音频只提交一个作业，全文开头按完整句意独立生成，并从完整WAV导出对应开头试听，不额外调用模型，不剪内部停顿。试听随全文完成后一起返回；不是提前下载试听、等待人工确认后再继续。单独的15秒预听按钮仍只生成短文，之后生成全文仍需新作业。

复用只接受本机最近100条记录中同一账号、数据集、任务类型、完整正文、实际读音稿、种子、语言、速度、语气、模板摘要、降噪及音量一致的已完成版本；校验音频和记录的SHA256。旧记录未留校验值、文件被移动/编辑、修改原音频模式或任何生成设置变化时不复用。复用另存新版本，原文件保留，不提交GPU作业；要重新随机生成，请关闭复用或使用新种子。该功能复用音频结果，并非让Kaggle GPU常驻。

Kaggle一次性作业间仍可能排队、安装依赖及加载模型；本版没有实现跨作业模型常驻或用户试听确认后的同GPU续作，不承诺固定节省分钟数。状态轮询间隔由20秒改为10秒，减少完成后的检测等待。

主页面移除重复的“详细调节”，统一从“更多设置”进入。模板页新增“清除选择”，切换到自然语气（无模板），不删除模板素材，老师音色参考保持不变。


## 0.6-preview.1：本机／云端双模式

在更多设置→连接与输出选择“本机生成”或“云端生成”。现有用户默认保留云端，不会自动安装大模型。配置检测只作建议，不自动改变生成方式；内存不足的电脑继续使用云端。NVIDIA显卡由nvidia-smi检测，PyTorch最终可用性仍在生成进程确认。

本机模式首次点击“安装本机模型环境”，在独立local_engine目录创建Python环境、安装匹配的torch/torchaudio 2.6.0及VoxCPM 2.0.3，下载模型到本机持久缓存。可能耗时较长并占用较多磁盘空间，至少预留14GB；不修改已安装的工作室12.11，不把大模型装进轻量客户端环境。系统建议为保守启发式，非模型官方最低配置：16GB内存及8GB NVIDIA显存可优先尝试GPU；CPU生成需当前可用内存至少12GB，速度必须实测。auto优先CUDA，不可用则CPU；指定cuda失败不会偷偷转用CPU。

首次安装包私下附带已确认老师原声，按SHA256校验。不含模型权重。公开代码更新包不含原声音频与模板；旧用户若本地没有原声缓存，可在本机设置选择原始WAV，或下载私下完整包。模板仍只提供节奏摘要，不作音色输入。

本机无需Kaggle账号或令牌。保留文字/TXT/SRT、15秒预听、全文、日语读音表、模板、倍数、普通微调、局部音频修改及无缝接回功能。由独立后台进程串行执行，连续生成只加载一次模型。切换CPU/GPU前先释放模型；更多设置可手动释放，关闭空闲语音窗口或退出程序也会释放。没有后台Web端口，不对外暴露推理服务。

失败记录和已完成段落保留，恢复同一本机任务时先校验断点并仅重做未完成段。日志可在最近任务日志查看。新内容的本机生成不排云端队，但首次下载安装、模型加载和实际推理仍需要时间；本机速度与实际硬件有关。自动化验证包含真实进程复用、模拟模型加载一次的多任务流程、原声校验、内存拦截和实际FFmpeg导出；每台组员电脑的CUDA推理及音色仍需15秒试听实测。
