# 杨宁云端语音克隆 · 0.2 独立试用版

双击 START_CLOUD_VOICE_PREVIEW.bat 启动。关闭旧试用窗口后，将此包解压到原试用目录并覆盖同名文件；连接信息保留。此包不升级或覆盖工作室12.11。

## 2026-11-10 更新

所有六种语言默认倍数统一为1.0。第一次启动此新版会将旧版保存的0.84、0.9等倍数重置为1.0；此后仍可手动选择倍数。语气模板不改变倍数，不复制模板的绝对音高。

“语气参考”默认载入已提供的日语模板和英语模板。日语用日语模板；英语、法语、德语用英语模板。粤语、印尼语暂未内置已确认模板，可自行选择音频或留空使用本语言自然语气。支持每种语言单独选择、更换模板。

模板只在本机分析最多前120秒的内部停顿与相对音高变化，转成柔和连贯的文字提示。模板原始波形、音色嵌入、绝对音高都不会送入模型；reference_wav_path只有已确认的1626原声，prompt_wav_path和prompt_text始终为空。模板摘要不能逐句精确转移语调，效果需试听。模板不用于加速、减速或剪掉自然停顿。

本包包含用户提供的两份语气模板，适合授权团队内部使用。源码仓库不包含这些音频。

## 云端连接

Kaggle账号先完成手机号验证，Notebook开启Internet并选用免费GPU。用户名、私有参考Dataset和令牌分别在连接栏填写；令牌保存在Windows凭据库。首次安装依赖和下载模型会耗时，免费GPU可用性按账号实际状态决定。

1626参考音频保留原始字节。兼容1626_reference.wav和Windows隐藏扩展名造成的1626_reference.wav.wav，并在新旧Kaggle输入目录中自动定位。只有SHA256匹配已确认原声才继续。

已修复VoxCPM2 2.0.3不接受seed参数的问题，改用PyTorch设种子。2026-11-10已在真实Kaggle T4任务跑通原声克隆并导出WAV；本次模板摘要功能通过本地调用检查，尚需真人试听验收。不要把格式检查通过当成音色、读音或模板语气验收。

## 全文和局部修改

可全文重新生成，也可选择完整句段后替换并导出新MP4/WAV/SRT。局部应包含前后自然停顿。新字幕为句级时长估算；旧烧录字幕需使用干净视频。保留原文件和接缝试听，成片需检查。

本地23项检查通过，覆盖FFmpeg真实导出、音高与停顿、任务恢复、模板仅发送摘要及模型音色输入隔离。更新后的Windows图形界面及模板控制效果仍需实际验收。
